# Metadata & Catalog Providers

::: tip Catalog Curation
Combining TMDB with CyberFlix allows you to browse current trending releases across major streaming networks within one unified interface.
:::

### Catalogs, Posters & Tracking

- ⭐ **[Cinemeta](https://www.stremio.com)** - Default official Stremio metadata provider indexing IMDb, TheMovieDB, and TVMaze.
- ⭐ **[The Movie Database (TMDB)](https://94c8cb9f702d-tmdb-addon.baby-beamup.club/configure)** / [Configurator](https://94c8cb9f702d-tmdb-addon.baby-beamup.club/configure) - Enhanced synopses, episode backdrop art, trailers, and multi-language localized titles.
- ⭐ **[Trakt.tv Integration](https://trakt.tv)** / [Stremio Addon](https://2ecbbd610840-trakt.baby-beamup.club/configure) - Syncs watch history, scrobbles playback progress across devices, and manages custom watchlists.
- **[CyberFlix Catalog](https://cyberflix.elfhosted.com/)** / [Configurator](https://cyberflix.elfhosted.com/) - Adds curated Netflix, Disney+, Apple TV+, HBO Max, and Amazon Prime browsing rows.
- **[Rating Poster Database (RPDB)](https://ratingposterdb.com)** / [Portal](https://ratingposterdb.com) - Replaces standard movie posters with high-quality posters overlayed with IMDb, Rotten Tomatoes, and Metacritic score badges. 🔑
