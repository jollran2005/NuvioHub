# Add-ons & Plugins

::: tip Setup Flow
Configure your scrapers with your Debrid API token first before installing them into your client. 🔑
:::

## 🧲 P2P & Torrent Scrapers

- ⭐ **[Torrentio](https://torrentio.strem.fun)** / [Configurator](https://torrentio.strem.fun/configure) - Primary torrent scraper and debrid resolver for Stremio. Supports RD, AD, PM, TorBox, and DL. 🔑
- ⭐ **[Comet](https://github.com/g0ldy/comet)** / [ElfHosted](https://comet.elfhosted.com/configure) - High-speed open-source Python Stremio addon with proxying and smart debrid caching. 🔑 💻
- **[Knightcrawler](https://knightcrawler.elfhosted.com)** / [Configurator](https://knightcrawler.elfhosted.com/configure) - ElfHosted community fork of Torrentio with alternative tracker sources. 🔑
- ⭐ **[MediaFusion](https://github.com/mhdzumair/MediaFusion)** / [Configurator](https://mediafusion.elfhosted.com/configure) - Multi-source scraper supporting movies, TV, anime, and live sports events. Self-hostable. 🔑 💻
- **[Annatar](https://github.com/gabedev/annatar)** / [Source Code](https://github.com/gabedev/annatar) - Lightweight torrent and debrid scraper written in Rust. 🔑 💻
- **[StremThru (Torz)](https://stremthru.13377001.xyz/stremio/torz/configure)** - Proxy and passthrough layer for Stremio addon traffic with torrent-focused routing and debrid integration. 🔑
- **[Peerflix](https://config.peerflix.mov/)** - P2P torrent scraper with a dedicated web configurator for source and debrid preferences. 🔑
- **[Meteor for the Weebs](http://meteorfortheweebs.midnightignite.me/configure)** - Anime-focused community scraper instance hosted on Midnight Ignite infrastructure.
- **[MediaFusion for the Weebs](http://mediafusionfortheweebs.midnightignite.me/app/configure)** - Anime-oriented MediaFusion instance with curated tracker and source preferences for Japanese media. 🔑
- **[TorrentsDB](https://torrentsdb.com/)** - Community torrent index with Stremio addon integration for direct debrid resolution. 🔑

## 🌐 HTTP Stream Addons

::: warning
HTTP stream addons serve third-party hosted content. Availability and reliability vary by provider. Always check addon uptime before reporting stream issues.
:::

- **[HDHub](https://hdhub.thevolecitor.qzz.io/)** - Community HTTP stream addon with an HD-focused content catalog.
- **[Pengu](https://pengu.uk/)** - General-purpose HTTP stream addon covering movies and TV series. Also provides live sports coverage — see [Live Sports Addons](#live-sports-addons).
- **[HD Plavio](https://hd.plavio.site/configure)** - Configurable HTTP stream addon with HD-prioritized source selection.
- **[CNCVerse](https://cncverse.dpdns.org/configure)** - Community HTTP stream addon with configurable source routing. Also covers live sports — see [Live Sports Addons](#live-sports-addons).
- **[BoringWays Pipe](https://pipe.boringways.workers.dev/configure)** - Cloudflare Workers-based stream proxy and request routing addon.
- **[ST Streams](https://st.111477.xyz/)** - Community-hosted HTTP stream source addon.
- **[WebStream RMBG](https://87d6a6ef6b58-webstreamrmbg.baby-beamup.club/configure)** - Community HTTP stream addon hosted on BeamUp infrastructure with a web configurator.
- **[FlixNest](https://flixnest.app/flix-streams/)** - HTTP stream addon with both on-demand movies/TV and live sports — see [Live Sports Addons](#live-sports-addons).
- **[Sooti](https://sooti.info/configure)** - Community HTTP stream addon with configurable source and quality preferences.

## 🏟️ Live Sports Addons

- ⭐ **[NuvioSports](https://nuviosports.xyz/)** - Dedicated live sports catalog addon built specifically for the Nuvio platform.
- **[HighFly Sports](https://sports.highfly.dev/configure)** - Configurable live sports stream addon with a web-based setup wizard.
- **[StremVerse](https://stremverse1.alwaysdata.net/)** - Community-hosted instance covering live sports events and scheduled match streams.
- **[NebulaProSports](https://sports.nebulapro.xyz/sports)** - Live sports stream addon from the NebulaProSports community with multi-sport coverage.
- **[Pengu](https://pengu.uk/)** - Provides a dedicated live sports section alongside its general on-demand HTTP stream catalog.
- **[CNCVerse](https://cncverse.dpdns.org/configure)** - Includes live sports event streams within its broader HTTP addon stream catalog.
- **[FlixNest](https://flixnest.app/flix-streams/)** - Covers live sports streams in addition to its on-demand movie and TV catalog.
- **[MediaFusion](https://mediafusion.elfhosted.com/configure)** - Multi-source debrid scraper with built-in live sports channels and event stream support. 🔑 💻

## 📋 Catalog & List Addons

- **[MyLists](https://mylistsaddon.com/catalogs)** - Personal list catalog addon for surfacing your own curated watchlists as a Nuvio or Stremio catalog row.
- **[Cinemeta v3](https://v3-cinemeta.strem.io/+)** - Official Stremio v3 metadata catalog providing rich movie and TV series information and search.
- **[TMDB Discover+](https://tmdb-discover-plus.elfhosted.com/)** - TMDB-powered catalog addon with advanced genre filtering, trending discovery, and collection browsing.
- **[Kartoons](https://kartoons.to/home)** - Cartoon and animated content catalog addon with dedicated kids, western animation, and anime sections.

## 🖼️ Poster & Metadata Providers

- **[AIOMetadata](https://aiometadata.elfhosted.com/configure)** - Power-user metadata addon pulling enriched data from TMDB, TVDB, TVMaze, MyAnimeList, IMDb, and Fanart.tv. 💻
- **[btttr](https://btttr.cc/)** - Community poster provider addon serving clean, high-quality artwork for Stremio and Nuvio title cards.
- **[Pictorium](https://pictorium.duckdns.org/)** - Self-hostable poster provider with support for custom poster libraries and artwork overrides. 💻
- **[PostersPlus](https://github.com/UmbraProjects/PostersPlus)** - Open-source poster enhancement addon that supplements standard artwork with extended cover art sources. 💻
- **[ExtendedRatings](https://extendedratings.com/)** - Injects extended rating data (IMDb, Rotten Tomatoes, Letterboxd) directly into stream and catalog metadata.
- **[TopPosters](https://top-posters.com/)** - Curated high-resolution poster source for Stremio and Nuvio title cards.
- **[RatingPosterDB](https://ratingposterdb.com/)** - Combined ratings database and poster provider serving artwork annotated with score overlays from multiple rating sources.

## 💬 Subtitle Addons

- ⭐ **[OpenSubtitles v3](https://opensubtitles-v3.strem.io/+)** - Official OpenSubtitles v3 Stremio addon. The recommended default subtitle source for broad language coverage.
- **[OpenSubtitles v3 Pro](https://opensubtitlesv3-pro.dexter21767.com/configure/)** - Enhanced OpenSubtitles v3 community build by dexter21767 with additional language options, hearing-impaired tracks, and format controls.
- **[Popcorn Notes](https://popcorn-notes.lsoares.workers.dev/)** - Lightweight subtitle addon running on Cloudflare Workers with low-latency subtitle delivery.
- **[RosettaSubs](https://rosettasubs.onrender.com/configure)** - Multi-language subtitle aggregator that consolidates results from several subtitle databases into a single ranked list.
- **[SubSense](https://subsense.nepiraw.com/)** - Subtitle discovery addon with configurable language priority ordering and fallback source options.
