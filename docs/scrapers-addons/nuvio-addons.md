# Nuvio Addons

::: tip Client-Side Resolution
Native addons operate directly within Nuvio's runtime, reducing reliance on remote third-party web scraper servers.
:::

- ⭐ **[Nuvio Core Provider](https://github.com/)** / [Source Code](https://github.com/) - Base provider suite supplying default scraping endpoints and metadata resolvers.
