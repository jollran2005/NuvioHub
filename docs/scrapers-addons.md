# Addons & Scrapers

::: tip Setup Flow
Configure your scrapers with your Debrid API token first before installing them into your client. 🔑
:::

## Stremio Addons

- ⭐ **[Torrentio](https://torrentio.strem.fun)** / [Configurator](https://torrentio.strem.fun/configure) - Primary Stremio scraper. Resolves torrents against Real-Debrid, AllDebrid, Premiumize, TorBox, and DebridLink. 🔑
- ⭐ **[Comet](https://github.com/g0ldy/comet)** / [GitHub](https://github.com/g0ldy/comet) - High-performance Python-based scraper addon with smart caching, Prowlarr/Zilean integrations, and debrid streaming. 🔑 💻
- **[Knightcrawler](https://knightcrawler.elfhosted.com)** / [Configurator](https://knightcrawler.elfhosted.com/configure) - Community fork of Torrentio hosted on ElfHosted infrastructure. 🔑
- **[MediaFusion](https://github.com/mhdzumair/MediaFusion)** / [GitHub](https://github.com/mhdzumair/MediaFusion) - Comprehensive scraper supporting films, series, live sports streams, and anime catalogs. 🔑 💻
- **[Annatar](https://github.com/gabedev/annatar)** / [GitHub](https://github.com/gabedev/annatar) - Ultra-lightweight torrent and debrid scraper written in Rust. 🔑 💻
- **[Jackettio](https://github.com/Jackettio/jackettio)** / [GitHub](https://github.com/Jackettio/jackettio) - Bridges self-hosted Jackett search engines directly into Stremio results. 🔑 💻

## Metadata & Catalog Providers

- ⭐ **[Cinemeta](https://www.stremio.com)** - Default official Stremio metadata provider indexing IMDb, TheMovieDB, and TVMaze.
- ⭐ **[The Movie Database (TMDB)](https://94c8cb9f702d-tmdb-addon.baby-beamup.club/configure)** / [Configurator](https://94c8cb9f702d-tmdb-addon.baby-beamup.club/configure) - Enhanced synopses, episode backdrop art, trailers, and multi-language localized titles.
- ⭐ **[Trakt.tv Integration](https://trakt.tv)** / [Stremio Addon](https://2ecbbd610840-trakt.baby-beamup.club/configure) - Syncs watch history, scrobbles playback progress across devices, and manages custom watchlists.
- **[CyberFlix Catalog](https://cyberflix.elfhosted.com/)** / [Configurator](https://cyberflix.elfhosted.com/) - Adds curated Netflix, Disney+, Apple TV+, HBO Max, and Amazon Prime browsing rows.
- **[Rating Poster Database (RPDB)](https://ratingposterdb.com)** / [Portal](https://ratingposterdb.com) - Replaces standard movie posters with high-quality posters overlayed with IMDb, Rotten Tomatoes, and Metacritic score badges. 🔑
