# Self-Hosting & Automation

::: tip Local & Cloud Hybrid
Self-hosting allows running local media servers (Plex, Jellyfin) while streaming directly from cloud debrid caches without consuming local storage.
:::

### Core Categories & Tools

- ⭐ **[AIO & Debrid Mounts](/self-hosting/aio-instances)** - Virtual filesystem tools (Zurg, Rclone, DMB) for mounting cloud debrid caches as local drives. 💻 🔑
- ⭐ **[The Arr Stack](/self-hosting/arr-stack)** - Automated media tracking and download managers (Prowlarr, Radarr, Sonarr, Bazarr). 💻
- **[Reverse Proxies & SSL](/self-hosting/reverse-proxy)** - Exposing and securing self-hosted services with NPM, Caddy, and Tailscale. 💻
