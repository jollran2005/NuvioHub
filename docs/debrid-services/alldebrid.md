# AllDebrid

::: warning 1-IP Policy Strictly Enforced
AllDebrid strictly monitors concurrent connections. Streaming simultaneously from two distinct public IP addresses under one account will trigger security warnings or temporary lockouts.
:::

### Core Portals & Resources

- ⭐ **[AllDebrid](https://alldebrid.com)** - Official website and subscription management portal.
- **[AllDebrid API Keys](https://alldebrid.com/apikeys)** - Generate and revoke individual application-specific API tokens. 🔑
- **[AllDebrid PIN Auth](https://alldebrid.com/pin)** - Device code pairing portal for TV and media center apps.
- **[AllDebrid Status Monitor](https://alldebrid.com/status)** - Live status and availability table for supported file hosters.
