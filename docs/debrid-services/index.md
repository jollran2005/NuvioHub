# Debrid Services

::: warning IP Concurrency Rule
Real-Debrid and AllDebrid strictly enforce a **single public IP** rule at any given moment. Streaming simultaneously from two locations will cause account suspension. Choose **Premiumize** or **TorBox Pro** for multi-location access.
:::

### Major Debrid Providers

- ⭐ **[Real-Debrid](https://real-debrid.com)** / [API Token](https://real-debrid.com/apitoken) / [Device Auth](https://real-debrid.com/device) - Highest torrent cache ratio and global CDNs. Single public IP only. 🔑
- ⭐ **[AllDebrid](https://alldebrid.com)** / [API Keys](https://alldebrid.com/apikeys) / [PIN Auth](https://alldebrid.com/pin) - High-throughput European multi-hoster with granular named API keys. Single public IP only. 🔑
- **[Premiumize.me](https://www.premiumize.me)** / [Account Dashboard](https://www.premiumize.me/account) - Multi-IP friendly provider with fair-use point system, cloud WebDAV drive, Usenet downloads, and VPN. 🔑
- **[TorBox](https://torbox.app)** / [API Settings](https://torbox.app/settings) - Modern cloud downloader featuring multi-IP allowances on paid tiers, direct NZB Usenet downloads, and Plex integration. 🔑
