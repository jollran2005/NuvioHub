# Usenet Integration

::: tip Fast NNTP Protocol
Usenet downloads occur directly from commercial server backbones over encrypted TLS/SSL connections at full gigabit speeds, without relying on active peer seeders.
:::

## Indexers

- ⭐ **[NZBGeek](https://nzbgeek.info)** - Community favorite indexer with open registration, active Discord, reliable Newznab API, and lifetime tier. 🔑
- ⭐ **[DrunkenSlug](https://drunkenslug.com)** - Highly regarded indexer with deep retention, reliable API scraping, and periodic open registrations. 🔑
- **[AltHUB](https://althub.co.za)** - Clean, reliable open-registration indexer offering affordable lifetime tiers and fast API response. 🔑
- **[Tabula Rasa](https://tabularasa.info)** - Active community indexer with open registration windows and robust release indexing. 🔑
- **[NinjaCentral](https://ninjacentral.co.za)** - High-volume indexer with rapid parsing of scene and P2P releases. 🔑

## Clients & Downloaders

- ⭐ **[SABnzbd](https://sabnzbd.org)** / [GitHub](https://github.com/sabnzbd/sabnzbd) / [Documentation](https://sabnzbd.org/wiki/) - Gold-standard open-source binary newsreader with automated PAR2 repair, unrar, and Arr integration. 💻
- ⭐ **[NZBGet](https://nzbget.com)** / [GitHub](https://github.com/nzbget-ng/nzbget) - High-efficiency C++ Usenet client engineered for maximum performance on low-power devices. 💻
