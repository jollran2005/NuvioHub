# Debrid Services

::: warning IP Concurrency Rule
Real-Debrid and AllDebrid strictly enforce a **single public IP** rule at any given moment. Streaming simultaneously from two locations will cause automated account suspension. Choose **Premiumize** or **TorBox Pro** for multi-location access.
:::

## Real-Debrid

- ⭐ **[Real-Debrid](https://real-debrid.com)** - Official homepage and account portal.
- **[Real-Debrid API Token](https://real-debrid.com/apitoken)** - Secret API token portal for scrapers, Zurg, and external tools. 🔑
- **[Real-Debrid Device Pairing](https://real-debrid.com/device)** - OAuth device code activation portal for TV clients and Kodi addons.
- **[Real-Debrid Speedtest](https://real-debrid.com/speedtest)** - Multi-CDN latency and bandwidth diagnostics test tool.
