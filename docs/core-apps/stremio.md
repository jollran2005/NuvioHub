# Stremio

::: tip Account Synchronization
Addons and library items configured on one device automatically synchronize across all signed-in desktop, TV, and mobile clients.
:::

### Official Clients & Builds

- ⭐ **[Stremio Desktop](https://www.stremio.com/downloads)** / [Flatpak](https://flathub.org/apps/com.stremio.Stremio) - Full native desktop client for macOS, Windows, and Linux.
- ⭐ **[Stremio Android TV](https://www.stremio.com/downloads)** / [Google Play](https://play.google.com/store/apps/details?id=com.stremio.one) - Leanback UI for television remotes, auto-frame-rate switching, and 4K HDR playback.
- **[Stremio Android Mobile](https://www.stremio.com/downloads)** - Touch-optimized mobile interface with background audio and casting capabilities.
- **[Stremio Web](https://web.stremio.com/)** - Browser-based client compatible with iOS via external player streaming. ℹ️

### Source Code & Repositories

- **[Stremio Core](https://github.com/Stremio/stremio-core)** - Core engine written in Rust.
- **[Stremio Shell](https://github.com/Stremio/stremio-shell)** - Official desktop Qt/C++ application shell.
