# Tools & Utilities

A curated catalog of companion web apps, account management utilities, homescreen builders, and device sideloading tools for Nuvio and Stremio.

## 🗂️ Catalog & Homescreen Builders

- ⭐ **[Xperience](https://xperience-app.com/)** / [Status](https://xperience-app.com/status) - Build a private Nuvio or Stremio homescreen catalog addon. Choose rows (Trending, genres, Trakt lists, AI picks), organize them into folders, and receive a personal manifest link to install.
- ⭐ **[Kaptain](https://kaptain.stream/)** - Homescreen and collections manager for Nuvio. Curate featured content rows, personal collections, and your homescreen layout without needing to build a full addon.
- **[StremList](https://stremlist.com/)** - Create and manage custom watchlists and catalog feeds installable inside Stremio or Nuvio.
- **[101 Catalogs](https://config.101catalogs.xyz/)** - Configurable multi-source catalog builder with a web-based setup interface for selecting and ordering catalog rows.
- **[Nuvio Collections Editor](https://yaarpatandaraa.github.io/nuvio-collections-editor/)** - Web-based editor for building and exporting custom Nuvio collection addons.
- **[Stremio Labar Catalogs](https://catalogs.stremiolabar.com/)** - Curated catalog feeds and community discovery lists by the Stremio Labar project.
- **[Stremio Labar Collections](https://collections.stremiolabar.com/)** - Thematic collection sets from Stremio Labar for organizing related content into shelves.

## 👤 Account & Profile Management

- ⭐ **[NuvioSync](https://nuviosync.com/)** / [Status](https://nuviosync.com/nuvio-status) - Migrate watchlists from Stremio, backup and restore Nuvio profiles, clone profiles between accounts, and import from Simkl.
- **[AIOManager](https://github.com/Sonicx161/AIOManager)** - Account management and configuration toolkit: save addon snapshots, sync settings across multiple accounts, and bulk-push addon load orders. 💻
- **[Numax](https://numaxofficial.website/)** - Account setup assistant and manager for configuring fresh Nuvio installs from scratch.
- **[NuvioAccountCloner](https://nuvio-account-cloner.vercel.app/)** - Quickly duplicate a Nuvio account's full addon and settings configuration to a new account.
- **[NuvioInstant](https://nuvioinstant.3hpm.ca/)** - Instant web-based Nuvio launcher for quick access without installing the desktop app.
- **[BingeCat](https://binge-cat.vercel.app/)** - Lightweight web interface for browsing and launching Nuvio content.

## 🎨 Badges, Formatting & Visual Enhancers

- **[Badger](https://nintle.github.io/Badger/)** - Generates and applies badge overlays (resolution, HDR, codec, audio channels) to stream result entries.
- **[BetterFormatter](https://9mousaa.github.io/BetterFormatter/)** - Stream result output formatter with customizable display templates and rules.
- **[Stream Format](https://format.crispytools.xyz/)** - Reformats and cleans up stream title labels for consistent, human-readable stream list entries.
- **[IntroDB](https://introdb.app/)** - Skip-intro database tool that marks intro and outro timestamps, enabling automatic intro skipping in compatible clients.

## 🤖 Stack Configurators & AIO Tools

- ⭐ **[AIOStreams](https://aiostreams.elfhosted.com/)** / [GitHub](https://github.com/Viren070/AIOStreams) - All-in-one stream aggregator that merges results from multiple scrapers into a single unified, ranked stream list with smart filtering. 🔑 💻
- **[UltraMax](https://ultramax.vip/setup.html)** - Guided setup wizard that configures a complete Stremio/Nuvio stack — scrapers, debrid services, and addons — in one flow. 🔑

## 📲 Device & Platform Tools

### Android TV & Fire OS

- ⭐ **[AFTVnews Downloader](https://www.aftvnews.com/downloader/)** - Essential browser and file downloader for installing APKs directly on Fire TV and Android TV using short codes.
- **[SendFilesToTV](https://sendfilestotv.app/)** - Local network transfer app for pushing downloaded `.apk` files directly from PC or mobile to your TV.
- **[NuvioBoost](https://github.com/Blorp-blorp/nuvio-boost)** - Post-install optimization script for Android TV to fine-tune system resources and improve Nuvio UI responsiveness. 💻

### Samsung Tizen

- ⭐ **[Apps2Samsung](https://apps2samsung.com/)** - Browser-based Tizen packaging and deployment utility to install custom `.wgt` applications (such as NuvioTVSmart) onto Samsung Smart TVs without needing a full Tizen Studio environment.
